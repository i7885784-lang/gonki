# Готовая игра для загрузки через браузер

[Скачать ZIP](https://raw.githubusercontent.com/i7885784-lang/gonki/main/downloads/gonki-browser.zip)

1. Скачайте ZIP и выберите в Windows «Извлечь всё».
2. Откройте https://app.netlify.com/drop.
3. Перетащите папку `gonki`, внутри которой лежит `index.html`, на страницу.
4. Откройте выданную ссылку. Создайте комнату и отправьте другу приглашение из игры.

Это готовая статическая сборка: установка Node.js, Git и запуск команд не нужны. Организатор должен держать вкладку с игрой открытой. Некоторые сети блокируют прямую связь WebRTC; TURN-сервер в этой версии не настроен.

По документации Netlify, публикация без входа временная: проект нужно забрать в аккаунт в течение часа, чтобы сохранить его. Для постоянной публикации используйте бесплатный план и проверьте, что сайт доступен публично.

Сборка: `npm run build:pages`. Архив проверен на целостность и наличие файлов, указанных в HTML. Код игры ранее прошёл модульные проверки и тесты двух браузеров в GitHub Actions (запуск 38536687817). Публикация этой сборки на Netlify ещё не проверена.
