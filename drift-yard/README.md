# Дрифт-двор — версия 0.11

Готовая браузерная 3D-игра: 10 автомобилей, гараж, покупки и тюнинг, 12 карт (8 гоночных и 4 дрифт-площадки), подвижные предметы на дрифт-картах. Работает без внешних библиотек и без звука.

## Быстрый запуск

Откройте `dist/index.html` в современном браузере с WebGL. Предпочтительно запустить локальный сервер: на Windows дважды нажмите `start-windows.bat` (нужен Python), затем откройте http://localhost:8000. Оставьте окно сервера открытым, пока играете.

На macOS/Linux из папки проекта:

```sh
python3 -m http.server 8000 --directory dist
```

## Загрузка на GitHub и ссылка на игру

Пошаговая инструкция — в [START_HERE.md](START_HERE.md). В комплекте готовая настройка GitHub Pages, которая публикует только папку `dist` после успешных тестов. Включите Pages в настройках своего репозитория.

## Управление

WASD / стрелки — управление, пробел — ручник, R — вернуть машину, C — сменить камеру, Esc / P — пауза. На телефоне используются экранные кнопки. В гараже перетаскивайте модель для вращения.

## Разработка

Сборка и установка зависимостей не нужны. Файлы игры находятся в `dist/`, проверки — в `tests/`. Для проверок нужен Node.js 22:

```sh
node --test tests/*.test.cjs
```

Подробности устройства игры — в [PROJECT_DETAILS.md](PROJECT_DETAILS.md).

Прогресс хранится в браузере каждого игрока. SDK Яндекс Игр, реклама, облачные сохранения и реальные платежи пока не подключены; покупки происходят за игровые кредиты.
