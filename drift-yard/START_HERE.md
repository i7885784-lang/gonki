# Как загрузить игру и дать брату ссылку

## 1. Распакуйте ZIP

Внутри находится папка `drift-yard`. Загружайте её содержимое, а не ZIP и не внешнюю папку целиком. В корне репозитория должны быть `README.md`, `dist`, `tests` и `.github`.

## 2. Создайте репозиторий

На GitHub создайте новый публичный репозиторий, например `drift-yard`. Основная ветка — `main`.

Удобный способ загрузки — GitHub Desktop: клонируйте созданный репозиторий, скопируйте в его папку всё содержимое `drift-yard` (включая `.github` и `.gitignore`), сделайте Commit и нажмите Push origin.

Через сайт GitHub можно использовать Add file → Upload files. Следите, чтобы загрузилась также папка `.github/workflows`: она нужна для публикации. Если браузер пропустил её, создайте файл `.github/workflows/pages.yml` через Add file → Create new file и вставьте содержимое одноимённого файла из архива.

## 3. Включите игру по ссылке

В репозитории откройте Settings → Pages. В разделе Build and deployment выберите Source → GitHub Actions.

Откройте вкладку Actions → Publish game → Run workflow → main → Run workflow. Если первый запуск до включения Pages завершился ошибкой, запустите его повторно после настройки.

Дождитесь успешного выполнения. Адрес появится в Settings → Pages и в результате задания deploy. Обычно он выглядит так:

`https://ВАШ-ЛОГИН.github.io/drift-yard/`

Отправляйте брату этот адрес, чтобы он мог играть. Ссылка на сам репозиторий подходит для скачивания и просмотра исходников.

После следующих загрузок в ветку main сайт обновится автоматически. Если репозиторий называется иначе, адрес тоже будет другим.

## Если используете терминал

В распакованной папке drift-yard (где лежит README.md):

```sh
git init
git add .
git commit -m "Initial game release v0.11"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

Этот вариант рассчитан на новый пустой репозиторий. Вместо ВАШ-ЛОГИН и ВАШ-РЕПОЗИТОРИЙ подставьте свои значения. Затем включите Pages по инструкции выше.

## Локальный запуск

Windows: start-windows.bat → откройте http://localhost:8000. Если Python не установлен, можно открыть dist/index.html напрямую. Сохранения локального файла и сайта могут различаться: прогресс хранится отдельно для каждого адреса в браузере.

Для остановки сервера нажмите Ctrl+C в его окне.

Официальная инструкция GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
